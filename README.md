# Hierarchical-Bayesian-Model-DomainAdaptation
Hierarchical Bayesian models are parameter-based because they define a structured probabilistic framework where parameters are learned at different levels of abstraction.


Define Hierarchical Bayesian Prior

A Hierarchical Bayesian Prior is a prior distribution placed on parameters within a hierarchical Bayesian model, allowing structured uncertainty modeling across multiple levels. Instead of assigning independent priors to each task or parameter, the hierarchical approach assumes that lower-level parameters are influenced by higher-level distributions.
